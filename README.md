# CareerBridge

**CareerBridge** is an AI-driven career guidance platform designed to help students and job seekers make better career decisions through intelligent resume analysis, personalized job recommendations, learning paths, skill-gap guidance, and an interactive career assistance chatbot.

## Key Features

- AI-powered resume analysis and scoring
- Personalized career recommendations
- Job recommendations based on skills and career interests
- Resume history management
- Skill-gap analysis
- Personalized learning paths
- Skill Practice Hub
- Interactive AI career chatbot
- Job application tracking
- HR candidate discovery and management
